# 课程资料共享站

一个给同学免费共享课程资料的网站。学生把笔记、真题、课件等文件上传，
别人可以搜索、筛选、下载。不收费、不挂广告、不用注册账号。

**免费、匿名、开放。** 设计上守三条底线：

1. **资料永久免费** — 不收费、不挂广告、不设下载门槛；
2. **平台代码开源** — AGPL-3.0，任何人都可以自建一份；
3. **信息开放可迁移** — 元数据用通用格式，上传者随时能拿走自己传的东西。

仓库含两个版本：**本机版**（根目录，Python 标准库，双击即用）和
**云端版**（`cloud/`，Cloudflare Workers + D1 + R2）。两者对比见下面的「当前进度」。

## 这个项目要解决的问题

大学里的复习资料（往年试题、笔记、课件）一直有需求，但没有一个公开、免费、
可检索的存放地点。结果是它们只能靠私聊和付费流通——想找的人找不到，
愿意分享的人也没有地方放。

这个项目想提供一个结构化的地方：上传门槛压到最低（不用注册、不用起名、
不用分类），搜索能按课程代码命中，文件永久免费下载。

### 关于匿名性

站点从设计上就不知道上传者是谁：不注册、不登录、不收邮箱，
身份只靠一个随机凭证（不对应任何真人），IP 仅以带密钥的 HMAC 形式保存
（不可反查）。上传的文件会自动剥离作者、公司、修订记录、EXIF GPS 等元数据。

## 当前进度

这是**第一阶段**：完整功能在本机跑通的版本，零云端依赖。

尚未实现（后续阶段）：云端部署、审核工作量分级（信任自动升级）、
举报推送、AI 检索、公开只读 API。

### 仓库里有两个版本

| 目录 | 是什么 | 技术栈 | 状态 |
| --- | --- | --- | --- |
| 根目录 | **本机版**：只在本机运行 | Python 标准库（`http.server` + `sqlite3`） | 已完成并实测通过 |
| `cloud/` | **云端版**：Cloudflare 部署用 | Workers + D1 + R2（JS） | 代码已完成、本地验证通过；**尚未部署到真云** |

云端版还多做了一层**上传准入机制**（本机版没有）：

- 按内容性质分两条通路 —— 版权类走「先上后诉」，高危类走「事前拦截」；
- 拦截发生在**写入存储之前**：命中的文件既不进数据库、也不落 R2；
- 独立的拦截留痕表 `intercept_log`（区别于记录审核员动作的 `audit_log`）；
- 高危关键词表**默认留空**，待填入。

云端版的说明见 `cloud/项目进度书.md`，部署前提与未验证项见 `cloud/SELF_TEST.md`。

> 云端版要真正上线，需要一个 Cloudflare 账号（本人注册）。在此之前，
> `wrangler.toml` 里的 `database_id` 仍是占位符。**本地验证通过 ≠ 云端可用。**

## 一、怎么启动

1. 确认电脑装了 Python 3（Windows 上一般自带 `py` 启动器）。
2. **双击 `start.bat`**。
3. 黑色窗口里会打印出访问地址，例如：

   ```
   首页：   http://127.0.0.1:8000/
   上传：   http://127.0.0.1:8000/upload
   管理页： http://127.0.0.1:8000/admin
   ```

4. 把地址复制到浏览器打开就能用。
5. 想停止服务：回到那个黑色窗口，按 `Ctrl + C`。

如果 8000 端口被别的程序占用了，程序会自动往后试 8001、8002……，
窗口里打印的地址以实际显示为准。

## 二、怎么进管理页

管理页需要**管理令牌**：

- 第一次启动时，程序会自动生成一个随机令牌，并打印在启动窗口里；
- 同时它也保存在 `config.ini` 的 `admin_token` 这一项里，可以自己改；
- 也可以用环境变量 `LDSG_ADMIN_TOKEN` 覆盖配置文件里的值。

进入方式：

1. 浏览器打开 `http://127.0.0.1:8000/admin`；
2. 输入启动窗口里显示的那串令牌；
3. 登录后可以：
   - 查看待审核资料，点「通过 / 拒绝 / 下架 / 恢复」；
   - 查看举报列表，把举报标记为「已处理」；
   - 查看全部资料的状态。

> 管理页的每个动作都会写进数据库的 `audit_log` 表。

## 四、元数据剥离模块（可单独调用）

上传时，`app.py` 会调用 `metadata.py` 里的 `strip_metadata()` 函数，
自动清除文档和图片里的隐私元数据：

- **PDF**：清除 `/Info` 里的 Author / Creator / Producer / Title 等，以及 XMP 元数据流；
- **Office（.docx / .pptx / .xlsx）**：清除作者、最后修改人、公司、经理、修订号、自定义属性；
- **图片（.jpg / .jpeg / .png）**：清除 EXIF、XMP、IPTC 和文本块。

这个函数和上传流程是分开的，可以单独拿来验证：

```bat
python metadata.py 原始文件.docx 清理后.docx
```

输出是一个 JSON，会告诉你处理类型、删掉了哪些字段、有没有注意事项。

也可以在 Python 里调用：

```python
import metadata
result = metadata.strip_metadata("原始文件.pdf", "清理后.pdf")
print(result)
```

> 已知限制：PDF 的元数据清理是「纯标准库」方案。如果元数据被压缩进 PDF 的
> 对象流里，明文搜索找不到，就无法清除。这一点在 `SELF_TEST.md` 里写明了。

## 五、功能一览

- 首页：列出已通过的资料，按上传时间倒序，每页 20 条；
- 搜索：按标题 / 课程代码 / 简介模糊匹配（回车或点按钮触发，不是实时搜索）；
- 筛选：课程代码、类别、学期，可以组合；
- 上传：拖入或选择文件，填表单提交；文件进入「待审核」；
- 详情页：显示完整信息、下载次数、浏览次数，带举报按钮；
- 下载：下载次数 +1（只有已通过的资料能下载）；
- 管理页：通过 / 拒绝 / 下架 / 恢复，举报列表；
- 关于页：版权说明与投诉通道占位文本。

### 硬性规则

- 单文件上限 **50 MB**，前端和后端都会校验，绕过前端也一样会被拒；
- 类型白名单：`pdf / docx / pptx / xlsx / zip / png / jpg / md / txt / epub`；
- 同一个文件（sha256 相同）二次上传会提示「已存在」，并给出原资料链接；
- 上传后状态是 `pending`，不会马上公开；
- 系统会生成规范文件名，原始文件名只保存在数据库里，只有管理页看得到；
- 同一份资料的未处理举报累计到 3 条，会自动把状态改成 `removed`（文件仍留在硬盘上）；
- 空结果、加载中、出错都有中文提示，不会白屏。

## 六、数据放在哪

所有数据都在本目录的 `data/` 文件夹里：

- `data/materials.db`：数据库，删掉它 = 清空所有记录（但不删文件）；
- `data/uploads/`：上传的文件本体。

备份就是把整个 `data/` 文件夹复制走。想彻底重来，关掉程序后删掉 `data/` 再启动即可。

## 七、常见问题

**Q：双击 `start.bat` 一闪而过？**
A：说明没找到 Python，或者程序启动就报错了。可以在黑窗口里看到错误信息；
也可以在本目录按住 Shift 右键 →「在此处打开 PowerShell 窗口」，
然后执行 `python app.py` 看完整报错。

**Q：忘了管理令牌怎么办？**
A：打开 `config.ini`，`admin_token` 那一行就是。

**Q：上传的文件会不会丢？**
A：不会。文件存在 `data/uploads/`，数据库只记录路径。下架也不会删文件。
